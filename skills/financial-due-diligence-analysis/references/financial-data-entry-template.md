## Entry rules

- If gross profit, EBITDA, or net income is entered, also provide the underlying line items or mark it as reported-only.
- If a value is estimated, label it `estimate` and explain the method.
- If a value covers multiple entities or products, state the allocation rule or leave the dimension blank.
- Do not mix tax-inclusive and tax-exclusive revenue without marking the basis.
- A filled template is supplied evidence; the Agent still needs to run reconciliation and source-quality checks.
